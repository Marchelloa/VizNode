# Правила работы Codex

## Изменения только после подтверждения

Codex не должен самостоятельно изменять файлы проекта.

Перед любым изменением Codex обязан:

1. Описать обнаруженную проблему или задачу.
2. Предложить один или несколько вариантов решения.
3. При необходимости показать небольшой прототип или пример предполагаемых изменений.
4. Кратко объяснить логику, последствия и компромиссы каждого варианта.
5. Получить явное подтверждение пользователя.

Только после явного подтверждения разрешается изменять файлы.

Без дополнительного подтверждения разрешены только действия чтения и анализа:

- просмотр файлов;
- поиск по проекту;
- проверка состояния Git;
- запуск безопасных диагностических команд;
- изучение логов и результатов тестов.

Разрешение на одно изменение не распространяется автоматически на последующие изменения.
Если в ходе работы возникает необходимость изменить дополнительные файлы или расширить согласованный объём, Codex должен снова запросить подтверждение.
